## ITU-R BS.1770 / pyloudnorm (credit)

The K-weighting filter implements ITU-R BS.1770-4. The analogue-prototype constants used to design it
for any sample rate are the commonly published values (also used by pyloudnorm, MIT,
https://github.com/csteinmetz1/pyloudnorm). No code is copied.
